# Execution Manager v0.1

نسخة أولية لإدارة تحصيلات العملاء ومصروفات تنفيذ التشطيبات.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع محتويات هذا المجلد إلى جذر مستودع GitHub ثم فعّل GitHub Pages.

## الوظائف الحالية
- إنشاء وإدارة أكثر من مشروع.
- تسجيل تحصيلات العميل.
- حفظ نسبة الربح المحجوزة وقت كل تحصيل (Snapshot).
- تسجيل المصروفات حسب بند التنفيذ ونوع المصروف.
- لوحة ملخص للتحصيل والربح المحجوز والمصروفات والمتاح للتنفيذ.
- حفظ البيانات محلياً في المتصفح باستخدام LocalStorage.

## حدود النسخة
هذه نسخة MVP محلية وليست نسخة إنتاجية. لا تتضمن حالياً قاعدة بيانات سحابية أو تسجيل دخول أو صلاحيات فريق أو حسابات صنايعية أو مزامنة بين الأجهزة. بيانات المتصفح لا تنتقل تلقائياً إلى جهاز آخر؛ احتفظ بنسخة احتياطية خارجية قبل تغيير الجهاز أو مسح بيانات المتصفح.
