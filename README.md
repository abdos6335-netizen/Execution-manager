# Execution Manager — Phase 1

تطبيق مستقل لإدارة الحسابات المالية لمشروعات تنفيذ التشطيبات. لا يعتمد على WeeklyPlanner ولا يتصل ببياناته أو Firebase الخاص به.

## الوظائف الحالية
- إدارة عدة مشروعات والتبديل بينها.
- لوحة ملخص للتحصيلات والربح المحجوز ومصروفات التنفيذ والمتاح المخصص للتنفيذ.
- تسجيل تحصيلات العميل مع حفظ نسبة الربح وقت تسجيل كل دفعة.
- إدارة بنود التنفيذ: الكمية والوحدة وطريقة الحساب والحالة.
- اتفاق مستقل للمونة والخامات واتفاق مستقل للأجرة داخل كل بند.
- إسناد المونة/المورد والأجرة/المقاول بشكل منفصل.
- حسابات مستقلة للمقاولين والصنايعية وكشف حساب لكل منهم.
- تسجيل دفعات المونة والأجرة وربط كل دفعة بالبند والمقاول المختار.
- تسجيل المصروفات المباشرة وربطها ببند عند الحاجة.
- نسخ احتياطي JSON وتصدير/استيراد البيانات.
- ترحيل تلقائي لبيانات النسخة المحلية السابقة عند أول تشغيل.

## طريقة التشغيل
افتح index.html أو استخدم رابط GitHub Pages بعد نشر التغييرات.

## التخزين وحدوده
النسخة الحالية تحفظ البيانات في LocalStorage على نفس المتصفح والجهاز. لا توجد حتى الآن مزامنة سحابية أو تسجيل دخول أو صلاحيات فريق؛ لذلك استخدم النسخ الاحتياطي قبل تغيير الجهاز أو مسح بيانات المتصفح.

## قواعد الحساب
- المدفوع للمقاول يسجل كحركة دفع واحدة في سجل الدفعات ويظهر في حساب البند وحساب المقاول.
- المصروف المباشر يسجل في سجل المصروفات ولا يكرر كدفعة مقاول.
- مصروفات التنفيذ في لوحة التحكم = المصروفات المباشرة + دفعات المقاولين.
- الربح المحجوز لكل تحصيل = قيمة التحصيل × نسبة الربح المحفوظة وقت التسجيل.
- المتاح المخصص للتنفيذ = إجمالي التحصيل − الربح المحجوز − مصروفات التنفيذ.
- هذا المؤشر ليس رصيد الخزنة النقدي الفعلي.


## Phase 2 — تحسينات الاستخدام الشخصي (أول دفعة)
- شاشة موحدة لتسجيل الحركة اليومية: خامات، مصروف عام، دفعة أجرة، أو تحصيل.
- اقتراح ربط البند والشخص، مع طلب تأكيد قبل إنشاء اسم جديد.
- إدخال صوتي بالعربية عبر دعم المتصفح (Web Speech API)، مع مراجعة النص قبل الحفظ.
- تقارير فورية حسب بند التنفيذ والشخص/المورد وإجمالي المشروع، قابلة للطباعة.
- لا يتم تغيير صيغة الحسابات أو حذف البيانات السابقة.
- ملاحظة: تحليل نص الحركة حاليًا مساعد لالتقاط المبلغ ونوع الحركة فقط؛ راجع الحقول يدويًا قبل التسجيل. قراءة تفاصيل الفواتير من الصور والمزامنة السحابية لم تُنفذا في هذه الدفعة.
