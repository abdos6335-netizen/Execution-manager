# Execution Manager

تطبيق مستقل لإدارة الحسابات المالية لمشروعات تنفيذ التشطيبات. لا يعتمد على WeeklyPlanner ولا يتصل ببياناته أو Firebase الخاص به.

## الوظائف الأساسية
- إدارة عدة مشروعات والتبديل بينها.
- لوحة ملخص للتحصيلات والربح المحجوز ومصروفات التنفيذ والمتاح المخصص للتنفيذ.
- تسجيل تحصيلات العميل مع حفظ نسبة الربح وقت تسجيل كل دفعة.
- إدارة بنود التنفيذ: الكمية والوحدة وطريقة الحساب والحالة.
- اتفاق مستقل للمونة والخامات واتفاق مستقل للأجرة داخل كل بند.
- إسناد المونة/المورد والأجرة/المقاول بشكل منفصل.
- حسابات مستقلة للمقاولين والصنايعية وكشف حساب لكل منهم.
- تسجيل دفعات المونة والأجرة وربط كل دفعة بالبند والمقاول المختار.
- تسجيل المصروفات المباشرة وربطها ببند عند الحاجة.
- نسخ احتياطي JSON واستيراد النسخ الحالية والقديمة.

## المرحلة الثانية — تسجيل يومي وتقارير ذكية مساعدة
- شاشة موحدة لتسجيل المصروفات والمشتريات ودفعات الأجرة والتحصيلات.
- كتابة الحركة باللغة الطبيعية؛ يساعد التحليل في التقاط المبلغ ونوع الحركة، مع مراجعة المستخدم للبند والشخص والمبلغ قبل الحفظ.
- إدخال صوتي بالعربية المصرية عبر Web Speech API عند دعم المتصفح.
- قراءة صور الفواتير مبدئيًا باستخدام Tesseract.js (عربي + إنجليزي)، واستخراج النص لمراجعته قبل التسجيل. يتطلب اتصال إنترنت لتحميل محرك OCR وملفات اللغة عند أول استخدام.
- اقتراح البنود والأشخاص المسجلين باستخدام الاسم أو الأسماء البديلة، مع تأكيد صريح قبل إنشاء سجل جديد.
- البحث داخل قوائم بنود التنفيذ والمقاولين والصنايعية، بالإضافة إلى البحث في تفاصيل الحركات.
- تعديل الأسماء البديلة للبنود والأشخاص من صفحات السجلات.
- تقارير حسب بند التنفيذ والشخص/المورد وإجمالي المشروع، مع بحث وفلاتر تاريخ ومقارنة بالفترة السابقة المماثلة، وطباعة التقرير.
- إجابات حسابية محلية محدودة للأسئلة الشائعة عن بند أو شخص أو التحصيلات أو المصروفات. هذه الإجابات مبنية على قواعد وبيانات السجلات وليست محادثة ذكاء اصطناعي مفتوحة.
- تنبيهات مساعدة للحركات المتطابقة المحتملة والمصروفات غير المصنفة.
- النسخة الاحتياطية الجديدة تتضمن إصدار المخطط وتاريخ التصدير، مع استمرار دعم ملفات النسخ القديمة.

## قواعد الحساب
- المدفوع للمقاول يسجل كحركة دفع واحدة في سجل الدفعات ويظهر في حساب البند وحساب المقاول.
- المصروف المباشر يسجل في سجل المصروفات ولا يكرر كدفعة مقاول.
- مصروفات التنفيذ في لوحة التحكم = المصروفات المباشرة + دفعات المقاولين.
- الربح المحجوز لكل تحصيل = قيمة التحصيل × نسبة الربح المحفوظة وقت التسجيل.
- المتاح المخصص للتنفيذ = إجمالي التحصيل − الربح المحجوز − مصروفات التنفيذ.
- هذا المؤشر ليس رصيد الخزنة النقدي الفعلي.

## التخزين والخصوصية
- البيانات محفوظة محليًا في LocalStorage على نفس المتصفح والجهاز.
- لا توجد مزامنة سحابية أو تسجيل دخول أو قاعدة بيانات مشتركة بين الأجهزة في المرحلة الثانية.
- استخدم التصدير الاحتياطي قبل استيراد نسخة أخرى أو تغيير الجهاز أو مسح بيانات المتصفح.
- الاستيراد يستبدل بيانات التطبيق الحالية بعد تأكيد المستخدم؛ يُنصح بتصدير نسخة حالية أولًا.

## حدود يجب معرفتها
- تحليل النص والصوت وOCR أدوات مساعدة فقط؛ راجع الحقول المستخرجة يدويًا قبل التسجيل.
- دقة OCR تتأثر بجودة الصورة والخط والإضاءة، وقد يحتاج تحميل محرك OCR وملفات اللغة إلى اتصال إنترنت.
- دعم الصوت يختلف حسب المتصفح والجهاز.
- لا يتم تنفيذ أي مزامنة سحابية في هذه المرحلة؛ المزامنة محفوظة للمرحلة الثالثة.
